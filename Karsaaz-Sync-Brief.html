1. Overview

What is Karsaaz Cloud?

Karsaaz Cloud is the internal file storage, document editing, and collaboration platform for Karsaaz EBS (Enterprise Business Suite). It is a fully self-hosted, airgapped, rebranded private cloud server — running entirely on Karsaaz infrastructure with zero dependency on any external service.

Think of it as Karsaaz's own private Google Drive — fully under our control, on our servers, branded as Karsaaz.

WebDAV — What It Is

WebDAV is the file sync protocol used by all desktop and mobile apps to connect to Karsaaz Cloud. It is NOT a separate app — it is the communication method built into the server. Think of it as the server address you paste into any sync app to connect it.

4. Critical Server Requirement

User-Agent — MUST Read This

The Karsaaz Cloud server identifies connecting clients by their User-Agent header. This is the single most important technical requirement for the developer.

CRITICAL: The User-Agent string in ALL Karsaaz Sync apps MUST NOT contain any of the following words:

mirall  ·  Nextcloud-android  ·  Nextcloud-iOS  ·  ownCloud-android  ·  ownCloud-iOS

If any of these appear in the User-Agent, the server is configured to block the connection.

Required User-Agent Format

AppRequired User-Agent
AndroidKarsaaz-Sync/1.0.0 (Android {version})
iOSKarsaaz-Sync/1.0.0 (iOS {version})
DesktopKarsaaz-Sync/1.0.0 (Windows/macOS/Linux)
This is a one-line change in each app's source code. It is simple but absolutely required. The server will reject any connection with the official Nextcloud User-Agent.
